Critères

Sens max : une valeur plus élevée est meilleure ; min : plus basse est meilleure (coût, délai…). Les colonnes préférence / q / p / s ne servent qu'à PROMETHEE (q : seuil d'indifférence, p : seuil de préférence stricte).

Attributs hors critères (budget, charge…) utilisables dans les contraintes

Alternatives et évaluations

Mode portefeuille

Chaque combinaison devient une alternative ; ses valeurs sont agrégées selon la colonne « agrégation ».

Contraintes

Filtres d'admissibilité (ex. charge ≤ 65) : une alternative qui les viole est exclue.

Surcharges de cellules (ex. valeurs corrigées par Delphi pour une combinaison)

Pondération des critères

Consultation Delphi

Pour une évaluation incertaine, saisissez les votes anonymes des experts tour par tour (ex. « 2, 1, 3, 3, 2 »). Valeur retenue : médiane du dernier tour. Consensus : écart interquartile ≤ seuil.

Chaque ligne modifie une valeur ; les lignes portant le même nom de scénario sont appliquées ensemble. Modifier un élément de base le ré-agrège dans toutes les combinaisons qui le contiennent.

Exporter le rapport

Le rapport reprend toutes les étapes : formulation, poids (et cohérence AHP), matrice, calculs intermédiaires de chaque méthode, comparaison, sensibilité, diagnostic et recommandation, avec les réglages des onglets Résultats et Sensibilité.
